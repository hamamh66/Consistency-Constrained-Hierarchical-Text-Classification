# Consistency-Constrained Hierarchical Text Classification

## Official implementation accompanying the paper

**Beyond Predefined Trees? Consistency-Constrained Multi-Level Classification and the Measured Limits of Adaptive Hierarchy Discovery**

This repository provides the official implementation of a reproducible framework for hierarchical text classification with consistency-constrained decoding.

## Highlights

- Consistency-constrained multi-level decoding
- Hierarchical text classification
- Label lattice construction
- Hierarchical evaluation metrics
- Exact-path accuracy
- Invalid-path elimination
- Adaptive hierarchy discovery evaluation
- Emerging-category detection experiments
- Comprehensive ablation studies
- Reproducible experimental pipeline

## Repository Structure

```text

├── tables/             Generated tables

```

## Implemented Methods

- Flat classifier
- Per-level independent classifier
- Top-down hierarchical classifier
- Consistency-constrained decoding
- Adaptive hierarchy discovery
- Confidence calibration

## Dataset

Experiments use the public Amazon Hierarchical Text Classification dataset.
